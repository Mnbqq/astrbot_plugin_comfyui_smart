# 行内参数手册

所有 `--参数` 都写在**指令后面、描述之后**，顺序随意。中英文写法等价（如 `--比例` = `--ratio`）。

```text
/画图 一个红发女孩 --ratio 3:4 --steps 30 --风格 赛博朋克 --画质 高清
/图生图 改成冬天 --denoise 0.7 --negative "lowres, bad hands"
/扩图 --left 256 --right 256
```

> 值里**有空格必须加引号**（`--negative "lowres, bad anatomy"`），否则后面的词会被当成描述。
> 检测到这种截断时，回执里会附一句提醒。

---

## 一、通用（所有出图指令都认）

| 参数 | 别名 | 取值 | 说明 |
|---|---|---|---|
| `--size` | `--尺寸` `--分辨率` | `1024x1024` / `1024*1024` / `1024×1024` | 直接指定宽高；会被底模架构的推荐像素归一 |
| `--ratio` | `--比例` | `1:1` `3:4` `16:9` … | 按比例算尺寸；**也可以裸写**：`/画图 16:9 一个女孩` |
| `--width` / `--height` | `--宽` `--w` / `--高` `--h` | 整数 | 只给一边时，另一边按比例补 |
| `--seed` | `--种子` | 整数，`-1`=随机 | 复现同一张图靠它 |
| `--steps` | `--步数` | 1–100 | 不写则按底模架构档案（SDXL 28 / SD1.5 25） |
| `--cfg` | — | 0–20 | 不写则按架构档案（SDXL 6.0 / SD1.5 7.0） |
| `--sampler` | `--采样器` | 采样器名 | 如 `euler_a`、`dpmpp_2m` |
| `--batch` | `--批次` | 1–8 | 一次出几张；超过 8 会被截到 8 |
| `--negative` | `--负面` | 逗号分隔 | 追加负面词；**值里有空格要加引号** |
| `--model` | `--模型` | 底模文件名 | 指定底模，优先于自动选型 |
| `--lora` | — | `名称` 或 `名称:权重` | 权重 0–2，只给名称时用默认 0.8 |
| `--provider` | `--模型商` | 后端名 | 多后端时指定跑哪台 ComfyUI |

### 提示词处理

| 参数 | 别名 | 说明 |
|---|---|---|
| `--llm` | `--优化` | 本次**强制**过一遍 LLM 改写 |
| `--no-llm` | `--不优化` `--no_llm` | 本次**跳过**改写，直接用你的原话 |
| `--委托` | `--commission` `--委托模式` | 允许 AI 补 1~3 个呈现层细节，并在结果里报账 |
| `--严格` | `--strict` | 本次压回「不许新增」的严格模式 |

### 画面风格三维（互不冲突，可叠加）

| 参数 | 别名 | 可选值 |
|---|---|---|
| `--风格` | `--style` `--画风` | `手办化` `立绘` `证件照` `游戏CG` `水彩` `复古胶片` `日韩画报` `2.5D` `动画电影感` `黑白漫画` `赛博朋克` `潮玩手办` |
| `--媒介` | `--media` | `照片` `插画` `3D` `像素` `水墨` |
| `--画质` | `--quality` | `标准` `高清` `极致`（**默认不加**，显式才生效） |

```text
/画图 一个女孩 --风格 赛博朋克 --媒介 照片 --画质 高清
```

自定义风格：`/风格 添加 <名称> <正向词>`，存 `data/style_presets.json`；`/风格` 查看全部。

### 画质增强

| 参数 | 别名 | 取值 | 说明 |
|---|---|---|---|
| `--hires` | — | 倍数 | 本次启用 hires fix；`0` 或 `1` 表示本次**关闭**（管理员可禁用它） |
| `--hires-denoise` | `--hires_denoise` | 0–1 | hires 第二步的重绘幅度 |
| `--hires-steps` | `--hires_steps` | 整数 | 第二步步数，`0` = 跟随主步数 |
| `--upscale` | `--放大` | `2` 或 `1920x1088` | 出图**之后**自动放大：单个数字=倍数，带 `x`=精确尺寸 |

## 二、`/图生图` `--denoise`（重绘幅度）

| 取值 | 效果 |
|---|---|
| `0.3` 左右 | 只修细节，构图几乎不变 |
| `0.5~0.6` | 改画风、改材质（默认 0.6） |
| `0.8+` | 接近重画，只保留大致构图 |

支持**多档一次出多张**：`--denoise 0.4,0.55,0.7` 会跑三次并分别回图。

---

## 三、ControlNet 深度控制（`/画图` + 参考图）

| 参数 | 别名 | 取值 | 默认 |
|---|---|---|---|
| `--control` | `--控制` `--controlnet` | `depth` | — |
| `--control-model` | `--控制模型` | 控制模型文件名 | 自动挑 |
| `--control-strength` | `--控制强度` | 0–2 | `0.8` |
| `--control-end` | `--控制结束` | 0–1 | `0.7` |

`--control-strength` 越大越贴参考图的构图，`--control-end` 控制「到第几步停止约束」。

> 深度预处理器权重是按需从 HuggingFace 下载的。提交前会先探测，探不通会**自动降级为图生图保构图**，而不是跑到一半报错。

---

## 四、`/扩图` 扩展量

| 参数 | 别名 | 取值 | 说明 |
|---|---|---|---|
| `--left` | `--左` `--左边` | 像素 | 向左扩 |
| `--right` | `--右` `--右边` | 像素 | 向右扩 |
| `--top` | `--上` `--上边` | 像素 | 向上扩 |
| `--bottom` | `--下` `--下边` | 像素 | 向下扩 |
| `--feather` | `--羽化` `--feathering` | 0–256 | 接缝羽化，默认 32 |

**只给部分边时，其余边为 0**：`--left 256 --right 256` 的语义是「只往左右扩」，不会偷偷加上下。
一个边都不给，则按原图比例自动决定扩哪边。

---

## 五、视频（`/视频` `/图生视频`）

| 参数 | 别名 | 取值 | 说明 |
|---|---|---|---|
| `--seconds` | `--时长` `--秒` `--second` | 0.5–600 | 目标时长，插件换算成帧数 |
| `--length` | `--帧数` `--frames` | 整数 | 直接给帧数（优先于 `--seconds`） |
| `--fps` | `--帧率` | 1–60 | 帧率，默认按模型原生（Wan 24fps） |

`/图生视频` 发**两张图**时，第一张当首帧、第二张当尾帧。

---

## 六、`/反推`

| 参数 | 别名 | 说明 |
|---|---|---|
| `--detail` | `--详细` `--分析` | 除英文 tag 外，再给一份**分区**中文分析（构图 / 光线色彩 / 画风 / 可疑处） |
| `--draw` | `--画` | 反推完**直接按反推结果出图**，不用再手打一遍 |
| `--provider` | `--模型商` | 指定用哪个对话模型看图 |
| `--llm` / `--no-llm` | — | 同上，控制是否二次改写 |

反推输出六个字段：`positive` / `negative` / `summary` / `character` / `work` / `bad_tags`。

## 七、其它指令

| 指令 | 参数 | 说明 |
|---|---|---|
| `/体检` | `--probe` `--探测` | 真跑一遍深度预处理器，验证权重能下载 |
| `/审计` | `--count` `--条数` | 看多少条（默认 20，上限 100） |
| `/审计` | `--user` `--用户` | 只看某个用户 ID |

## 八、常见坑

| 现象 | 原因 |
|---|---|
| `--negative lowres, bad hands` 后面的词跑进描述了 | 值里有空格没加引号，写成 `--negative "lowres, bad hands"` |
| `--ar 16:9` 没生效 | 没有 `--ar` 这个参数，用 `--ratio` 或裸写 `16:9` |
| `--画质 高清` 没反应 | 检查拼写：档位是 `标准` / `高清` / `极致`，不是 `high` |
| `--hires 2` 没用 | 配置里 `hires.allow_inline` 被关了（管理员限制，防止有人开爆显存） |
| `--upscale` 没发生 | 功能开关 `features.upscale` 没开 |
